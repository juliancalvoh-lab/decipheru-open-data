# DecipherU open data

Two small datasets from https://decipheru.com/data, released under CC BY 4.0.

| File | Rows | What it holds |
| --- | --- | --- |
| `exam-facts.csv` / `.json` | 30 | Questions, time allowed, passing standard, fee and retake rule for the license exams DecipherU covers. One row per fact. |
| `licensing-costs.csv` / `.json` | 63 | Fees, required training hours, minimum age and record policy, by state and license. |

Every row carries the owner's page, the date we read it, and a link back to the DecipherU page. Blank means not verified, never zero.

Published by DecipherU Editorial, drafted with AI assistance from the cited sources and kept under the founder's supervision. Found an error? https://decipheru.com/corrections

The live versions at https://decipheru.com/data are the source of truth; this repository is a dated snapshot (2026-11-17).
